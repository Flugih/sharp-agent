# Документ Word

1. Подготовь текст документа в разметке Markdown:
   - заголовки: `# Заголовок`, `## Подзаголовок`, `### Раздел`;
   - абзацы — обычный текст, между абзацами пустая строка;
   - маркированный список — строки с `- `, нумерованный — с `1. `;
   - таблица — строки вида `| Ячейка | Ячейка |`, вторая строка `|---|---|` отделяет шапку;
   - **жирный**, *курсив*, `моноширинный`;
   - блок кода — между строками ```;
   - разрыв страницы — отдельная строка `---page---`.
2. Вызови run_plugin: name = `word`, script = `make-docx.ps1`,
   arguments = {"Markdown": "<весь текст документа>", "Target": "<полный путь к файлу .docx>"}.
   Если текст уже лежит в файле .md или .txt, вместо Markdown передай "Source": "<полный путь к этому файлу>".
   Путь к файлу передавай только в "Source" и "Target"; программа проверит его и откажет, если это `.env`, папка
   `auth\` или служебные файлы, — тогда выбери другое место.
3. Если файл уже существует, скрипт откажется его заменять. Спроси пользователя и только с его согласия
   повтори вызов с "Overwrite": "yes" — или выбери другое имя.
4. В ответе коротко скажи, что документ готов, и назови его по имени — программа сама покажет его карточкой.
