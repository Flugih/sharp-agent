---
name: data
description: Конвертировать CSV и JSON, посчитать статистику столбца, подготовить отчёт и построить график.
---
Вызови `process-data.ps1` через run_plugin. `Source` — CSV или JSON с массивом записей. Для CSV укажи `Delimiter`: точка с запятой по умолчанию, запятая или один другой символ.

- `Mode=convert`: выбери `Target` с расширением JSON или CSV. CSV подходит для плоских записей.
- `Mode=report`: выбери JSON или Markdown. `Column` — числовой столбец. Отчёт содержит число строк, пропуски, минимум, максимум, среднее и сумму.
- `Mode=chart`: выбери PNG. `Column` — числа, `LabelColumn` — подписи. Для одного читаемого графика подготовь до 100 строк.

Числа допускают точку или запятую. Вложенные поля JSON сохраняются при записи JSON. Дополнительные программы не нужны. Для замены результата используй `Overwrite=yes` с подтверждением.
