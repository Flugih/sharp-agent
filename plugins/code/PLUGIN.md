Для существующего проекта запусти `inspect-project.ps1` через run_plugin с `Source` — папкой проекта. Скрипт покажет манифесты, состояние Git и последние коммиты. Состояние Git доступно после установки Git и только в репозитории.

После этого прочитай манифест и нужные файлы через read_file и search_text. Для нового проекта создай структуру и файлы штатными инструментами. Для тестов и сборки выбери команду из манифеста проекта и используй run_command в папке проекта, чтобы пользователь видел команду и мог её подтвердить. В ревью приводи файл, строку, конкретный дефект и способ его проверить. Коммиты, публикацию и изменение истории выполняй только по просьбе пользователя.
