# Таблица Excel

1. Подготовь данные в формате CSV: первая строка — шапка, разделитель — точка с запятой.
   Значения с разделителем или кавычками заключай в кавычки, кавычку внутри удваивай.
   Числа пиши без пробелов, дробную часть — через точку или запятую: так они станут числами в Excel.
2. Вызови run_plugin: name = `excel`, script = `make-xlsx.ps1`,
   arguments = {"Csv": "<все строки CSV>", "Target": "<полный путь к файлу .xlsx>", "Sheet": "<название листа>"}.
   Если данные уже лежат в файле .csv, вместо Csv передай "Source": "<полный путь к этому файлу>".
   Путь к файлу передавай только в "Source" и "Target"; программа проверит его и откажет, если это `.env`, папка
   `auth\` или служебные файлы, — тогда выбери другое место.
3. Если файл уже существует, скрипт откажется его заменять. Спроси пользователя и только с его согласия
   повтори вызов с "Overwrite": "yes" — или выбери другое имя.
4. В ответе коротко скажи, что таблица готова, и назови её по имени — программа сама покажет её карточкой.
